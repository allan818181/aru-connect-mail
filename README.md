## Overview

React + TypeScript campus email client for Ardhi University: inbox, compose and reader, plus an admin console for bulk email, department announcements, users and analytics.

## Features

- Inbox list, email viewer and compose modal
- Admin console: bulk email, department announcements, user management
- Email statistics, user activity and analytics overview
- Profile, settings and help pages; light/dark theme

## Tech stack

TypeScript · React · Vite · Tailwind CSS · shadcn/ui

## Getting started

```bash
cd frontend
npm install
npm run dev
```

## Project structure

`frontend/src/components/email` mail UI · `frontend/src/components/admin` admin console · `frontend/src/pages`
